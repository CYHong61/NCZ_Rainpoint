# 기존 사이트(레인 포인트 통합 데모)에서 추출한 데이터

원본: 업로드해 주신 `레인 포인트 통합 데모` html(199KB, 데이터가 파일 안에 내장되어 있음). 파일 안의 상수(GEO, DONG, FAC, PTS, MONTH_RAIN, GUS)를 그대로 JSON으로 꺼냈습니다. 값은 바꾸지 않았습니다.

| 파일 | 내용 |
|---|---|
| `seoul8_dong_geo.json` | 서울 8개 구 82개 동 경계(SVG path). 좌표계 1500×1033. `dongs[]`(gu, name, d), `gus`, `ctx` 포함 |
| `seoul8_dong_stats.json` | 동별 건축면적(㎡), 세대수, 빗물이용시설 수 (82개 동) |
| `seoul8_facility_points.json` | 빗물이용시설 위치 472곳. **경도·위도가 아니라 동 경계와 같은 SVG 좌표(x, y)** |
| `seoul_monthly_rain_mm.json` | 서울 월별 평년 강수량(기상청 1991~2020, 연 1,417.9mm) |

대상 8개 구: 강남구, 서초구, 송파구, 강동구, 관악구, 광진구, 동작구, 성동구

## 원 출처 (기존 사이트 푸터 기준)
- 건축HUB(국토교통부) 건축물대장 표제부 (2026.8 기준)
- 기상청 서울 평년값 (1991~2020)
- 서울특별시 빗물이용시설 공간정보 (서울 열린데이터광장 SP_LGRC_AS, 2022-04-03 기준, 삭제 표시 40건 제외). 위치·등록번호만 있어 **건물 용도와 용량은 알 수 없음**
- 경계: 행정안전부 도로명주소 법정동 경계(2015, southkorea/seoul-maps 재가공)
- 박윤경 외(2022) 한국수자원학회 학술발표회

## 기존 산정식 (참고용)
확보빗물량(㎥) = 건축면적 × 연강수량 × 유출계수(0.85) × 포집률. 환급 관련 계산(1,100원/㎥ 등)은 B2C 보상 설계용이라 새 사이트에서는 쓰지 않는 것을 권장합니다.

## 새 사이트에서 쓸 때 주의
1. **좌표가 SVG 투영 좌표**입니다. 지도 라이브러리(Leaflet 등)에 올리려면 경위도가 필요하므로, 원본 서울시 공간정보(SP_LGRC_AS)에서 경위도를 다시 받아야 합니다. 지금 파일은 기존처럼 SVG로 그릴 때만 바로 쓸 수 있습니다.
2. 시설 위치 데이터에는 **법정/비법정, 센서 설치, 시범 여부 필드가 없습니다.** 새 방향에서 필요한 필드는 `record_schema.json`의 `facility_fields`를 참고해 추가하세요.
3. 기존 사이트 푸터는 "시행규칙 제4조"를 저류조 용량(지붕 집수면적 × 0.05m 이상) 근거로 적고 있습니다. 반면 사용량 기록 3년 보존은 팀이 원문에서 확인한 시행규칙 제4조 조항(기록 항목)을 근거로 하고 있어, **조·항 번호를 새 사이트에 쓰기 전에 원문으로 다시 맞춰 보세요.**
4. 건축면적 기준 값이며, 실제 지붕 집수면적이나 시설 용량이 아닙니다.
