# 레인 포인트 (Rain Point)

빗물이용시설의 사용 실적을 센서로 재고 증명하는 서비스의 웹사이트 데이터 저장소입니다.
2026 대한민국 물산업 혁신 창업대전 아이디어 부문(물이용) · 팀 늙치즈 · 경희대학교 환경학및환경공학과

## 서비스 한 줄
빗물 사용량을 자동으로 기록하고, 시설별 정상 기준과 비교해 이상을 알리고, 법이 요구하는 기록과 지자체 점검표를 만들어 줍니다.

## 화면 구성 (대상별 모듈)
- 시설 관리자용: 홈 · 시설 상세·이상 진단 · 법정 기록 · 운영 추천 · ESG 리포트 · 서비스·사업 구조
- 지자체용: 홈 · 관할 시설 현황 · 시설 지도 · 점검표 · 서비스·사업 구조
- 화면은 `js/app.js` 위쪽의 `MODULES`에서 대상별로 켜고 끕니다. 화면 이름을 넣거나 빼면 메뉴가 바뀝니다.
- 관할 시설 현황의 시설 12곳은 모두 가상이며 시뮬레이션입니다.

## 열어 보기
- 로컬: `index.html`을 브라우저로 열면 됩니다. 서버나 설치가 필요 없습니다.
- 공개: GitHub 저장소의 Settings → Pages에서 Branch를 main(/root)로 지정하면 주소가 생깁니다.
- 데이터를 고쳤다면 `python3 build_data.py`로 `js/data.js`를 다시 만드세요. (화면은 `js/data.js`를 읽습니다)

## 폴더 구조
```
index.html  css/style.css  js/app.js  js/data.js  build_data.py
data/
  facts.json            문제 통계, 법령, 공개 사례 (항목별 확인 상태 포함)
  sim_results.json      시뮬레이션 결과 (가정 모형, 실측 아님)
  demo_timeseries.json  이상 진단 화면용 가상 시설 데이터 (시뮬레이션)
  record_schema.json    법정 기록·지자체 점검표 필드 초안
  esg_kpi.json          ESG 지표와 크레딧 단계
  legacy/               서울 8개 구 동 경계·시설 위치(SVG 좌표)·월별 강수량 (README 참고)
```

## 데이터 주의
- `sim_results.json`, `demo_timeseries.json`은 서울 기상청 ASOS 시간 강우(2015~2025)와 가정 모형으로 만든 **시뮬레이션 값이며 실제 측정값이 아닙니다.**
- `facts.json`의 `status`가 "확인"이 아닌 항목은 출처 확인 중입니다.
- 출처: 국회법률정보시스템(법령), 성남시 2026 물 재이용시설 관리 및 기술지원 용역 과업지시서, 한국건설기술연구원 외(2022), 서울 열린데이터광장 빗물이용시설 공간정보, 건축HUB 건축물대장, 기상청.
